# Рабочие материалы Полины

В репозитории находятся последние версии материалов для проекта «Света».

## Что где находится

- `index.html` — локальная версия каталога 207 картин;
- `artworks.json` — данные карточек: авторы, названия, годы, описания и места хранения;
- `locations.csv` — короткий список «название картины — место хранения»;
- `originals/` — 207 оригиналов картин;
- `fragments/` — 207 подготовленных фрагментов для вывода на «Свету».

## Что исправлено в онлайн-каталоге

> Обновление от 21 октября 2026 года: исправлены места хранения во всех 207 карточках.

- в поле места хранения теперь указан один основной музей или одно актуальное место;
- из заключительных фраз описаний убраны перечисления нескольких музеев и «других собраний»;
- каждое описание заканчивается понятной строкой `Место хранения: …`;
- изображения и 12 тематических подборок сохранены.

Примеры после исправления:

- «Южный ветер. Ясный день („Красная Фудзи“)» — **Метрополитен-музей, Нью-Йорк**;
- «Армадный портрет Елизаветы I» — **Королевские музеи Гринвича, Лондон**;
- «Нападение на дворец Сандзё» — **Музей изящных искусств, Бостон**.

Скачайте репозиторий целиком и откройте `index.html`. Не отделяйте HTML от папок `originals` и `fragments`.
