# Рабочие материалы Полины

В репозитории находятся последние версии материалов для проекта «Света»:

- `index.html` — каталог 207 картин с описаниями и нормализованными местами хранения;
- `artworks.json` — данные карточек;
- `locations.csv` — список названий и мест хранения;
- `originals/` — 207 оригиналов картин;
- `fragments/` — 207 подготовленных фрагментов для вывода на «Свету».

## Онлайн-каталог

[Открыть каталог Kosmos Laboratory](https://katalog.kosmoslaboratory.ru)

## Как открыть локальный каталог

Скачайте репозиторий целиком и откройте `index.html`. Не отделяйте HTML от папок `originals` и `fragments`.
